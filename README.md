# 山河同契

**以山河为契，结同袍之队。**

简体中文 | [English](README.en.md)

</div>

**山河同契**（Bonded Peaks）是一个基于 **NeoForge 26.1 / Minecraft 26.1** 的轻量队伍模组。玩家可以创建队伍、邀请好友入队、使用队伍专属聊天，并由队长统一管理成员。所有数据随世界存档持久化保存，服务器重启不丢失。

当前版本：`0.0.1`（早期开发版）

## 功能特性

- 创建与解散队伍，队名最长 12 个字符
- 邀请制加入：队长邀请 → 玩家接受（邀请 60 秒内有效）
- 队伍专属聊天：`/bp <消息>` 快捷发言
- 完整的队长管理：踢人、转让队长、两步确认解散
- 队伍列表与详情查询，离线成员名通过缓存显示
- 数据自动持久化，随世界存档保存

## 环境要求

| 项目 | 要求 |
|---|---|
| Minecraft | 26.1.2（声明兼容范围 `[26.1, 26.2)`） |
| NeoForge | 26.1.2.8-beta 或更新（声明兼容范围 `[26,)`） |
| Java | 构建需要 JDK 25 |
| 前置依赖 | AnvilLib（network、config 模块），已通过 JarJar 内嵌，无需单独安装 |

## 安装方法

1. 下载 `bonded-peaks-26.1.2-<版本>.jar`（主 jar 即可，依赖已内嵌）
2. 放入客户端的 `.minecraft/mods/` 目录，或服务器的 `mods/` 目录
3. 启动游戏，在聊天框输入 `/bondedpeaks` 查看帮助

> [!TIP]
> 模组逻辑全部在服务端，但消息文本由客户端翻译。若客户端未安装本模组，玩家会看到原始翻译键（如 `commands.bonded_peaks.help.1`）。**建议服务器与所有玩家都安装本模组。**

## 用户指引

### 基本概念

- 每支队伍有且仅有一名**队长**（Owner），其余为**成员**（Member）
- 每名玩家同一时间只能属于一支队伍
- 队长专属权限：邀请、踢人、转让队长、解散队伍
- 成员可执行：退出队伍、队伍聊天

### 命令总览

| 命令 | 权限 | 说明 |
|---|---|---|
| `/bondedpeaks` | 所有玩家 | 显示帮助信息 |
| `/bondedpeaks create <队名>` | 所有玩家 | 创建队伍并成为队长 |
| `/bondedpeaks invite <玩家>` | 队长 | 邀请玩家加入队伍 |
| `/bondedpeaks accept` | 所有玩家 | 接受最近收到的邀请 |
| `/bondedpeaks accept <邀请者>` | 所有玩家 | 接受指定邀请者发出的邀请 |
| `/bondedpeaks leave` | 成员 | 退出当前队伍 |
| `/bondedpeaks disband` | 队长 | 发起解散（需二次确认） |
| `/bondedpeaks confirm` | 队长 | 确认解散队伍 |
| `/bondedpeaks kick <玩家>` | 队长 | 将成员移出队伍 |
| `/bondedpeaks transfer <玩家>` | 队长 | 将队长之位转让给队内成员 |
| `/bondedpeaks list` | 所有玩家 | 列出服务器上所有队伍 |
| `/bondedpeaks info [队名]` | 所有玩家 | 查看队伍详情（不填队名则查看自己的队伍） |
| `/bondedpeaks chat <消息>` | 成员 | 向全队发送消息，可简写为 `/bp <消息>` |

### 常见流程

**创建队伍**

```
/bondedpeaks create 山河
```

队名规则：

- 只能包含字母或数字（支持中文等 Unicode 文字），不能包含空格或符号
- 最长 12 个字符
- 不区分大小写（`Abc` 与 `abc` 视为同一队名），不可与现有队伍重名

**邀请与加入**

1. 队长执行 `/bondedpeaks invite <玩家名>`，向对方发出邀请
2. 被邀请的玩家执行 `/bondedpeaks accept` 加入队伍；若同时收到多份邀请，可用 `/bondedpeaks accept <邀请者>` 指定接受谁的邀请
3. 邀请在发出 **60 秒**后自动失效；过期后需队长重新邀请
4. 目标玩家只需曾被服务器识别（登录过本服）即可被邀请；对方不在线也可邀请，其上线时会自动收到待处理邀请的提醒

**队伍聊天**

```
/bp 今晚七点山顶集合！
```

消息将以 `[同契·队名] 玩家名：消息` 的格式发送给所有在线成员，聊天内容仅队员可见。

**管理队伍（队长）**

- 踢人：`/bondedpeaks kick <玩家名>`
- 转让队长：`/bondedpeaks transfer <玩家名>`（被转让者须为队员；转让后该队所有未处理邀请作废）
- 解散队伍：先执行 `/bondedpeaks disband`，再执行 `/bondedpeaks confirm` 确认
  - 队长在确认前下线，解散流程自动取消
  - 解散后所有成员自动离队，相关邀请全部失效

**退出队伍（成员）**

```
/bondedpeaks leave
```

队长不能直接退出队伍，须先转让队长或解散队伍。

### 规则与限制

- 每人只能属于一支队伍；已在队内时无法再创建队伍或接受邀请
- 邀请他人时，对方必须不在任何队伍中；不能邀请自己
- 队长不能踢自己（请使用 `leave` 或 `transfer`），不能把队长转让给自己
- 队长发起解散后若下线，待确认的解散自动取消
- 邀请与待确认的解散仅保存在内存中，**服务器重启后失效**，需重新邀请/重新发起解散
- 所有命令仅玩家可执行，控制台不可用
- 当前版本未接入权限系统，任何玩家均可使用全部命令

### 数据存储与备份

队伍数据保存在世界存档目录下的 `serverconfig/bonded_peaks/`：

```
<世界目录>/serverconfig/bonded_peaks/
├── teams/           # 每支队伍一个 JSON 文件（<队名>_<哈希>.json）
└── players.json     # 玩家名缓存（用于离线成员名的显示）
```

数据在每次变更时自动保存；备份世界存档即可同时备份队伍数据。**不要在服务器运行时手动编辑这些文件。**

## 从源码构建

环境要求：JDK 25 + Git

```bash
git clone <仓库地址>
cd bonded-peaks
./gradlew build
```

构建产物位于 `build/libs/`：

- `bonded-peaks-26.1.2-<版本>.jar` — 主 jar
- `bonded-peaks-26.1.2-<版本>-sources.jar` — 源码 jar

开发常用命令：

```bash
./gradlew runClient    # 运行客户端
./gradlew runServer    # 运行服务端
./gradlew runData      # 运行数据生成
./gradlew build        # 构建
```

欢迎通过 Issue 反馈问题、通过 PR 贡献代码（PR 会自动执行构建检查）。

## 常见问题

**Q：收到的消息显示为一串英文键名（如 `commands.bonded_peaks.help.1`）？**

A：客户端未安装本模组，无法翻译消息文本。请让所有玩家也安装本模组。

**Q：接受邀请时提示"此邀已散，如风过岭"？**

A：邀请已过期（60 秒）、对方队伍已解散或队长已变更，请让队长重新邀请。

**Q：队长想退队怎么办？**

A：先执行 `/bondedpeaks transfer <队员>` 转让队长，再执行 `/bondedpeaks leave`；或直接解散队伍。

**Q：服务器重启后队伍还在吗？**

A：在。队伍数据随世界存档持久化保存；但未接受的邀请和待确认的解散会失效。

**Q：控制台（服务器终端）能使用这些命令吗？**

A：不能。所有命令都要求由游戏内玩家执行。
